# E-vent

Dashboard front-end para organização e acompanhamento de eventos. Projeto de portfólio focado em React, TypeScript, gerenciamento de estado e experiência de usuário.

## Destaques

- Dashboard responsivo.
- Criação, edição e exclusão de eventos.
- Busca e filtros combináveis.
- Indicadores derivados do estado da aplicação.
- Persistência com `localStorage`.
- Fluxo de status dos eventos.
- Validação nativa de formulários.
- Estados vazios e feedback de interação.
- Controles responsivos e acessíveis.
- GitHub Actions para validação TypeScript e build.

## Stack

- React
- TypeScript
- Vite
- CSS
- GitHub Actions

## Executar

```bash
npm install
npm run dev
```

Validação de produção:

```bash
npm run lint
npm run build
```

## Arquitetura atual

```text
src/
├── App.tsx
├── main.tsx
└── styles.css
```

Os dados são locais ao navegador. O projeto não possui backend, autenticação ou banco de dados.

## Papel no portfólio

O E-vent demonstra domínio prático de fundamentos modernos de Front-end e serve como projeto intermediário entre interfaces estáticas e aplicações orientadas a produto, como TechDesk e RaceMetrics.
